# WSTWND Creative

Landing page for WSTWND Creative, live at https://wstwndcreative.github.io

## Editing the page

All the words, buttons, ticket details and the reel live in **`_data/site.yml`**. The page layout reads from that file, so you never need to touch `index.html` to change copy.

**Easiest: Pages CMS (visual editor, free)**
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open `WSTWNDCreative/WSTWNDCreative.github.io` and choose **Landing page**.
3. Edit the fields, then **Save**. The live site updates about a minute later.

**Or on GitHub:** open `_data/site.yml`, click the pencil icon, edit, and commit.

Tips:
- In headings, wrap one word in `*asterisks*` to set it in italics.
- Each section (How it works, Who it's for, Watch party) has a `show` switch to hide it.
- Add or remove steps, cards and ticket rows freely; the layout adjusts.
- Upload a new reel to the `media` folder (vertical MP4, keep it under ~5 MB).
